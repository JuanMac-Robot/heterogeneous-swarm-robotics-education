# Aerial Swarm

The aerial swarm will be developed using Crazyflie drones and the Lighthouse positioning system.

## Main Components

- Crazyflie drones
- Crazyradio communication
- Lighthouse positioning system
- Position and orientation estimation
- Autonomous flight
- Multi-drone control
- Formation control
- Swarm algorithms

## Development Process

The aerial swarm will be developed progressively:

1. Configure one Crazyflie
2. Establish communication with the drone
3. Configure the Lighthouse positioning system
4. Obtain real-time drone position
5. Implement autonomous takeoff and landing
6. Implement waypoint navigation
7. Control multiple Crazyflie drones
8. Implement formation algorithms
9. Develop aerial swarm behaviors

## Educational Objectives

Students will learn:

- Aerial robotics
- Robot localization
- Wireless communication
- Autonomous flight
- Multi-robot control
- Formation control
- Swarm robotics
