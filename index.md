# Heterogeneous Swarm Robotics Education

## Two Swarms. One Mission.

This project focuses on the development of heterogeneous robotic swarms composed of aerial and ground robots.

### Ground Swarm
ESP32-controlled robots using ArUco localization and an overhead camera.

### Aerial Swarm
Crazyflie drones using Lighthouse localization.

### Final Objective
Integrate both swarms into a cooperative heterogeneous robotic system for search-and-rescue applications.
