# Heterogeneous Swarm Robotics Education

## Two Swarms. One Mission.
## [Project Description](project-description.md)

Learn about the motivation, objectives, system architecture, development stages, educational goals, and final mission of the Heterogeneous Swarm Robotics project.

[Ground Swarm](ground-swarm.md) |
[Aerial Swarm](aerial-swarm.md) |
[Heterogeneous Swarm](heterogeneous-swarm.md)

This project explores the development of heterogeneous robotic swarms composed of aerial and ground robots.

The main application of the project is **Search and Rescue**, although the same technologies may later be applied to exploration, surveillance, transportation, human assistance, and security.

---

## [Ground Swarm](ground-swarm.md)

The ground swarm will be developed using mobile robots controlled by ESP32 microcontrollers.

Students will develop:

- Robot communication
- Motion control
- ArUco-based localization
- Overhead camera vision
- Autonomous navigation
- Swarm formation algorithms

---

## [Aerial Swarm](aerial-swarm.md)

The aerial swarm will be developed using Crazyflie drones.

Students will develop:

- Crazyflie communication
- Lighthouse localization
- Autonomous flight
- Multi-drone control
- Formation algorithms
- Swarm navigation

---

## [Heterogeneous Swarm](heterogeneous-swarm.md)

The final objective is to integrate the aerial and ground swarms into a cooperative robotic system.

The two swarms have different:

- Localization systems
- Communication systems
- Robot dynamics
- Control architectures

One of the main engineering challenges of the project is to develop a common architecture that allows both swarms to collaborate.

---

## Educational Goal

Students will learn the complete process of developing a swarm robotics system:

**Individual Robot → Multi-Robot System → Swarm → Heterogeneous Swarm → Cooperative Mission**

---

## Final Mission

The final system will demonstrate cooperation between aerial and ground robots in a simulated Search and Rescue mission.
