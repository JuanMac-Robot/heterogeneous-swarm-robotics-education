# Ground Swarm

The ground swarm will be developed using mobile robots controlled by ESP32 microcontrollers.

## Main Components

- ESP32-based robot control
- Wireless communication
- Overhead camera
- ArUco markers
- Global robot localization
- Closed-loop navigation
- Formation control
- Swarm algorithms

## Development Process

The ground swarm will be developed progressively:

1. Control one robot
2. Establish communication with the robot
3. Detect the robot using an ArUco marker
4. Estimate robot position and orientation
5. Implement closed-loop navigation
6. Control multiple robots
7. Implement formation algorithms
8. Develop swarm behaviors

## Educational Objectives

Students will learn:

- Embedded programming
- Wireless communication
- Computer vision
- Robot localization
- Navigation
- Multi-robot control
- Swarm robotics


## Ground Robot Navigation

Learn the fundamentals of autonomous ground robot navigation, including goal attraction, sigmoid obstacle avoidance, and 360-degree sensing.
